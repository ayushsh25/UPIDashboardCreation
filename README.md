# Personal Finance Dashboard UI

A responsive personal finance dashboard UI designed in Figma to create a more useful and engaging banking experience throughout the day.

## Project Overview

This project explores how a financial dashboard can change based on the user's time of day, activity, and financial context.

Instead of showing the same information throughout the day, the dashboard provides three different experiences:

### 🌅 9:00 AM — Plan Your Day

The morning dashboard helps users start their day by showing:

- Available balance
- Daily spending budget
- Spending so far
- Remaining budget
- Upcoming financial activities
- Morning financial overview

### ☀️ 2:00 PM — Track Your Progress

The afternoon dashboard focuses on spending awareness:

- Amount spent
- Remaining daily budget
- Budget usage percentage
- Spending categories
- Where the user's money went
- Personalized spending insights

### 🌆 5:00 PM — Reflect & Get Rewarded

The evening dashboard helps users review their financial activity:

- Total amount spent
- Amount under budget
- Number of transactions
- Money-saving streak
- Daily financial progress
- Reward/achievement concepts

## Design Goal

The main goal of the project is to make a banking dashboard more useful and engaging than a traditional dashboard that mainly displays balance and recent transactions.

The experience follows a simple daily journey:

**PLAN → TRACK → REFLECT & REWARD**

This gives users relevant information at different moments of the day and encourages them to return to the app.

## Design Approach

The dashboard was designed around user behaviour throughout the day. Each state prioritizes different information depending on what the user is likely to need at that moment.

The morning state focuses on planning, the afternoon state focuses on awareness and spending control, and the evening state focuses on reflection, achievements, and motivation.

## Responsive Design

The interface is designed to adapt to different screen sizes while maintaining:

- Clear visual hierarchy
- Readable typography
- Consistent spacing
- Accessible touch targets
- Flexible card layouts
- Simple navigation

## Project Status

This is a **UI/UX design concept created in Figma**.

The project focuses primarily on visual design, user experience, responsive layouts, and the concept of time-based personalization. It is not intended to represent a fully connected banking or UPI application.
